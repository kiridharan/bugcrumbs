# @bugcrumbs/screenshot

DOM screenshots for [Bugcrumbs](https://github.com/kiridharan/bugcrumbs), loaded on demand by the widget so it never adds to your app's initial bundle. The Bugcrumbs widget is left out, and sensitive form fields are masked.

You don't need to install it directly: `@bugcrumbs/react` depends on it.

Screenshots are re-rendered from the DOM, so cross-origin images, canvas and video may be missing. MIT licence.
